This is a guide on how to use eSim on an iPhone using Airalo

## Reminders

1. Be sure to have a stable internet connection.
2. Install at home then activate later when you arrive in your destination.
3. Avoid interrupting the installation process.
4. Don't delete the esim.

## Installation and activation via Airalo

1. Click view instructions.
2. Choose Direct installation.
3. Next
4. Install eSIM
5. Continue
6. Continue again
7. Wait for 2 minutes
8. Select the Default line (Choose primary so you can still receive calls or messages through you main SIM).
9. Select iMessage and Facetime (Choose primary)
10. Mobile Data (Choose Primary if you won't use it yet or Personal if you'll use it already)
11. Keep "Allow Mobile Data Switching" turned off.
12. Continue.
13. The eSIM is successfully installed.

## Activating eSIM when you arrive at destination.

1. Settings
2. Cellular
3. Click Travel
4. Mobile Plan Label - Rename it to something relevant to your trip.
5. Make sure "Turn on this line" is toggled on.
6. Set Network Selection to Automatic.
7. Check Mobile/Cellular Data Network and make sure the apn is filled in. If apn isn't filled in, go back to the Airalo app > View instructions > Scroll down to apn > Copy and paste information
8. Choose Low Data Mode
9. Toggle Data Roaming on

## To make sure you don't use your home data when you're away:

1. Go to Settings.
2. Mobile Service
3. Find Primary SIM and click
4. Scroll down
5. Toggle the Data Roaming off

To track data usage, check the Airalo app or use its widget
