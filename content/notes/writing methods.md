# Other methods

This is a running list of writing methods that I'm using or aim to use.

- Collect seeds, meditate on them and write lengthier journal entries on them, publish them later.
- Choose events, flesh them out in journal, develop them further for publication.
- Walk. Write thoughts as they come. Write images as they come. Photograph. Return home and put everything on the canvass. This could apply for both poetry and prose.
