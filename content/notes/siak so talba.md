Siak so Talba

(Patalos na "Ako ang Daigdig" nën Alejandro Abadilla)

I

siak  
so talba

siak  
so anlong

siak  
so talba  
na anlong  
say anlong  
na talba

siak  
so maandon siak  
say ag ompatëy a siak  
say anlong na talba

II

siak  
so talba na anlong  
siak  
so anlong na talba

siak so bulos a siak  
matoor ëd inkasiak  
ëd talbak  
na anlong

siak  
so anlong  
na talba

siak  
so talba  
na anlong  
siak

III

siak  
so liknaa'y  
bulos

siak  
so talinta-on  
mabilay

siak  
so bilay  
a andi anggaan

siak  
so liknaan  
say talinta-o  
say bilay

liknaan  
talinta-o  
bilay  
anlong  
siak

IV

siak  
so talba  
ëd anlong

siak  
so anlong  
ëd talba

siak  
so talba

siak  
so anlong

talba  
anlong  
siak....
