One poem = one image (most haikus)
One poem = multiple images (list poem)
One poem = multiple images and multiple senses ([[trish shihikura|Trish Shihikura]] and [[dennis aguinaldo|Dennis Aguinaldo]])

[[metaphor|Metaphor]] is still image. You use image to help readers see another image better, especially when that image eludes description. For example, you won't understand my depression symptom. But if I say brain fog or brain zap, you might understand it.

To get better with images, practice writing poems filled with them.

Some exercises:
1. Write a poem from a photograph. Try to use images only.
2. Write a two-line poem with two images and the poem is a simile.
3. Write a poem that is an extended simile.
4. Write a poem that is an extended metaphor.
